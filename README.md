🚀 Project Overview: E-commerce Customer Churn Analysis
This project focuses on identifying patterns and predicting customer attrition for an e-commerce platform. By analyzing demographic data, transaction history, and customer behavior, the goal is to provide actionable insights that can help improve customer retention strategies.  

🛠️ Technical Stack
Database Management: MySQL / PostgreSQL  

Data Cleaning: SQL (handling NULL values, timestamp formatting, and deduplication)  

Analysis: Customer segmentation and churn prediction  

📊 Key Features of the Dataset
The analysis is built upon a comprehensive dataset of over 5,000 customers, including metrics such as:  

Customer Tenure: Duration of the relationship with the platform.  

Satisfaction Scores: Direct feedback ranging from 1 to 5.  

Behavioral Data: App usage hours, preferred login devices, and complaint history.  

Financial Trends: Cashback amounts and year-over-year order hikes.  

🔍 Core Objectives
Data Integrity: Clean and preprocess raw e-commerce data, specifically targeting missing values in Tenure and HourSpendOnApp.  

Churn Correlation: Determine the relationship between customer complaints and the likelihood of churn.  

Revenue Impact: Analyze how discount usage (coupons) and cashback influence long-term customer loyalty.  

📈 Business Insights
Retention Triggers: Identifying the "City Tier" or "Preferred Payment Mode" most associated with high churn rates.  

Logistics Optimization: Evaluating if the distance from the warehouse to the home impacts customer satisfaction scores.
